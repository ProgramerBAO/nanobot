# nanobot 报表平台使用教程（公司内部）

> 面向使用者：怎样在飞书里问报表、怎样设置定时播报、怎样看懂卡片。
> 管理员的配置入口见第 5 节。产品能力清单与数据口径的权威定义见
> [PRODUCT.md](PRODUCT.md)。

## 1. 开始之前

- 你需要：飞书里已添加报表机器人（私聊或在已拉入机器人的群里@它）。
- 普通查询和订阅**只需要聊天**，不需要任何网页。
- 网页管理台（Report platform）给管理员用，需要登录地址和管理 token（找部署负责人拿）。
- 不确定能说什么？直接发 **`帮助`** 或 **`报表中心`**，机器人会列出当前可用的全部问法示例。

## 2. 三分钟上手：先发这五句

| 你想看什么 | 直接发送（可复制） |
| --- | --- |
| 今天各客户用了多少 | `多客户多模型日报简报` |
| 三个客户今早的吞吐 | `查看阳春面、豆汁、佛跳墙全部模型上一小时 TPM` |
| 某个模型的日报 | `Kimi-K3模型的日报（全部客户）` |
| 我定了哪些播报 | `查看我的订阅` |
| 我最近生成过什么 | `查看最近报表` |

> 提示：`阳春面`、`豆汁` 这类中文名是客户别名，由管理员在管理台维护（见 5.2）；
> 也可以直接用客户英文标识（如 `tencent_token_hub`）。

## 3. 随查随用：日常报表

以下问法都是"确定性路由"——不经过大模型自由发挥，识别即执行，卡片立即返回。

### 3.1 用量简报（日 / 周 / 月）

| 想要 | 发送 |
| --- | --- |
| 我的日报/周报简报 | `我要日报`、`我要周报` |
| 某模型全部客户的日报 | `Kimi-K3模型的日报（全部客户）` |
| 某客户近 7 天 | `tencent_token_hub 近7天使用情况` |
| 多客户多模型日报简报 | `多客户多模型日报简报` |
| 指定客户的多模型日报简报 | `阳春面、豆汁、佛跳墙全部模型的多客户日报简报` |
| 多客户周报 | `各客户模型周报` |

简报卡每行是"模型｜Token 数｜同比｜环比"：

- **数值单位是 K/M/B**：`1K`=1,000、`1M`=100 万、`1B`=10 亿（例如 `11.09B` 就是 110.92 亿）。
- **同比 / 环比**只显示百分比；变化幅度达到提醒阈值（默认 30%，管理员可调）时会带 **📈（大涨）/📉（大跌）**。
- 卡片下方有"进一步分析"按钮，一键进入同一范围的详细矩阵报表。

### 3.2 多客户多模型小时 TPM 报告（最常用）

发送：`查看阳春面、豆汁、佛跳墙全部模型上一小时 TPM`
（或指定模型：`佛跳墙 Kimi-K3 上一小时 TPM 峰值和均值`）

卡片怎么读：

- 副标题 `09-17 17:00–18:00 · 3 客户 / 8 模型 · 3 机器空闲`——数据永远是**刚结束的上一完整小时**。
- **模型明细表**（六列）：客户 | 模型 | 峰值 | 均值 | 机器占用 | 机器真实使用。
  - 峰值/均值为该小时的 maxTpm / avgTpm，K/M/B 单位。
  - 机器两列是**平台级**数据（与具体客户无关，同一模型在不同客户行显示相同值）；
    `（闲N）` 表示占用比真实使用多 N 台机器。
  - `暂不可用` = 上游该小时没有这个数；`暂无用量` = 该小时确实没有请求。
- **集群机器库存表**（第二张卡）：集群 | 机器总数 | 空闲 | 生产 | 测试 | 开发 | 备用，
  生产 = 总数 − 其余各项；机器总数为 0 的集群不显示（折叠说明里会注明隐藏了几个）。
- 展开卡片底部"**报表说明与数据质量**"可看完整口径与本次的数据质量告警。

### 3.3 其他报表

| 报表 | 发送 | 说明 |
| --- | --- | --- |
| 单机折算 TPM 峰值 | `Kimi-K3 单机 TPM 峰值` | 按集群/卡型展示，不代表具体机器 |
| 平台健康报告 | `健康报告`、`近15分钟健康` | 错误率/延迟/TTFT 快照 |
| 供应商质量 | `供应商质量报告`、`Kimi-K3 各供应商性能对比` | 按开关开放 |
| 成本/账单 | `成本报告` | 默认关闭，需部署时开启 |

有灵活查询权限的同学还可以直接问管理数据，例如
`tencent_token_hub 有哪些 Endpoint`、`Kimi-K3 配置在哪些集群`、`查看某客户最近的账单`。

## 4. 定时播报：订阅

### 4.1 创建（说一句话 + 点一次确认）

发送一句"**谁 + 什么报表 + 什么时候发**"，机器人回一张确认卡，点"确认创建订阅"即生效。

| 想要的节奏 | 发送 |
| --- | --- |
| 每天上午十点 | `每天上午十点发送阳春面、豆汁、佛跳墙全部模型的多客户日报简报` |
| 工作日 | `工作日上午十点发送阳春面全部模型的日报简报` |
| 每周一 / 每月 1 日 | `每周一上午十点发送…`、`每月1日十点发送…` |
| 每小时（整点后 5 分钟） | `每小时播报上一小时阳春面、豆汁、佛跳墙全部模型的TPM` |
| **指定几个小时** | `每天9点、10点播报上一小时阳春面、豆汁、佛跳墙全部模型TPM` |
| 顺着一张卡片定 | 生成任意报表后，**引用该卡片**回复：`工作日上午十点发送给我` |

要点：

- 动词说 `发送 / 播报 / 推送 / 报` 都行。
- **指定小时的语义**：`9点` = 当天 09:05 投递 08:00–09:00 的数据（整点后 5 分钟是为了等上游聚合完成）。
- 同一会话里创建一模一样的订阅会被拦截（提示"已存在"）；想在**多个群**都收到同一条播报，见 5.1 的"投递会话"。
- 确认卡会列出识别到的客户清单；有客户名没匹配上时会明确告诉你哪些未包含，不会悄悄丢客户。

### 4.2 管理

- 发送 `查看我的订阅`（或 `我的订阅` / `订阅管理`）：列出全部订阅，每条带
  **启用/停用** 按钮；删除走管理台。
- 一条订阅投递到多个会话时，订阅卡会标注"投递组 N 会话"。
- 修改节奏 / 范围 / 投递目标：在管理台编辑（下节）。

## 5. 管理台（WebUI · Report platform）

浏览器打开管理地址（部署负责人提供），用管理 token 登录。共四个页签：

### 5.1 订阅管理（最常用）

- **新建 / 编辑订阅**：结构化表单选报表类型、客户（实时目录勾选）、模型范围、
  发送频率（含"每小时"和指定小时）、时区、推送渠道。
  - **投递会话**：一行填多个会话/群标识（顿号分隔，首个为主投递），
    保存后同一内容会同时投到所有列出的会话（上限 20 个）；
    列表里显示"投递 N 会话"徽标。
- **涨跌提醒阈值**（本页顶部）：同比/环比幅度达到该百分比（默认 30）时卡片带
  📈/📉。改成 50 并保存后，30%–50% 的变化就不再标记；**保存立即生效，无需重启**。
- **客户名称映射**：维护"中文名 → 真实客户 ID"（如 `糖番茄 → tenant-b4n1…`）。
  保存后聊天里立刻可以用中文名匹配客户；"恢复默认"回到 config 文件里的配置。

### 5.2 报表类型

每个报表的**启用/停用**和**是否允许订阅**（模板策略，带版本号防并发覆盖）。
停用一个报表立即生效：不再执行、不再显示、不能新建订阅；已有订阅保留。

### 5.3 权限管理（RBAC）

按"渠道 + 用户"授予 Connector / Template / 客户 / 模型 / 订阅模板权限；
开启 RBAC 后服务端逐项校验。日常不需要动。

### 5.4 功能开关

行为级开关（订阅机制、自然语言订阅、简报默认路由、管理界面等），
切换即时生效并记录管理审计。计算口径类配置（语义版本、阈值、扩展连接）仍属部署配置。

## 6. 看懂卡片：数据质量与状态

| 你看到的 | 含义 | 需要处理吗 |
| --- | --- | --- |
| （无任何质量提示） | 数据完整 | 否 |
| `数据质量：partial` | 部分数据缺失（卡片会注明缺哪项，如某模型机器占用缺失） | 偶发可忽略；持续出现找管理员 |
| `暂不可用` | 上游该时段没有这个数（不是 0） | 否 |
| `暂无用量` | 该时段确实没有请求（真实的 0 用量） | 否 |
| `（本期无用量）`提醒卡 | 订阅到点时所有客户在该窗口都没有可用量的模型 | 否，有用量后自动恢复完整报表 |
| `本期无用量客户：X、Y` | 部分客户无用量，报表只包含其余客户 | 否 |
| 📈 / 📉 | 变化幅度达到提醒阈值 | 按需关注 |

原则：**"成功但无用量"和"查询失败"是两种不同的状态**，卡片永远不会把失败伪装成 0。

## 7. 常见问题

**Q：说了客户中文名没反应？**
先确认管理员在"客户名称映射"里配置了该别名且保存过（保存即生效）；
如果配了还不行，可能是该客户当天没有用量（见"本期无用量"），不是别名失效。

**Q：指定了 9 点播报，怎么 9:05 才收到？**
设计如此：整点后 5 分钟投递，等待上游小时聚合完成，数据才是完整的 8–9 点。

**Q：提示"相同报表和发送计划的订阅已经存在"？**
同一会话里已有完全相同的订阅。想给别的群也发，去管理台编辑该订阅、
在"投递会话"里加目标，而不是在两个群各建一条。

**Q：订阅到点没收到，也没有报错？**
查看运行记录（管理台或 `查看最近报表`）：
- 状态 ok + "本期无用量" → 该时段无用量，正常；
- 状态 ok 且应有卡片 → 找管理员查投递日志；
- 状态 error → 卡片/记录里会带原因。

**Q：想改播报时间/客户范围？**
管理台 → 订阅管理 → 对应行"编辑"，改完保存即生效（编辑会同步更新定时任务）。

**Q：数值怎么突然从"亿"变成 B 了？**
全平台统一为 K/M/B 单位（1M=100 万、1B=10 亿），数值本身没变。
